# Security policy

Only the latest commit on `main` is supported during the research phase.

Do not open a public issue for suspected data-isolation or authorization vulnerabilities. Use GitHub private vulnerability reporting when enabled, or contact the repository owner privately.

Include the affected commit, reproduction steps, expected and observed behavior, whether a synthetic canary was exposed, and a suggested remediation when available.

This repository is a research prototype and must not be treated as a production security boundary without independent review.
