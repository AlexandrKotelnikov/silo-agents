# Contributing

1. Open an issue describing the research question or defect.
2. Keep pull requests focused and add tests for behavioral or policy changes.
3. Never commit proprietary documents, credentials, personal data, or employer information.
4. Use synthetic canaries for leakage demonstrations.
5. Run `ruff check .`, `mypy src`, and `pytest -q` before submitting.
6. Document security-relevant architectural changes as ADRs.

By contributing, you agree that your contribution is licensed under Apache-2.0.
